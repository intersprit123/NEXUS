# NEXUS ⚡

NEXUS is an all-in-one interactive cyber-learning platform MVP.

## Included
- Cyber command-center dashboard
- XP, levels, streaks and skill bars
- Mission control
- Interactive fictional investigation
- Safe simulated terminal
- Cyber toolkit shell
- Academy progression
- CTF entry point

## Run
Open index.html directly, or serve the folder:

python3 -m http.server 8080

Then visit http://localhost:8080.

All challenge content in this MVP is fictional and sandboxed.
